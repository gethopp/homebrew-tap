# gethopp/homebrew-tap

Homebrew tap for [Gister](https://github.com/gethopp/gister), a local-first GitHub Gist manager.

## Install

```sh
brew install --cask gethopp/tap/gister
```

or:

```sh
brew tap gethopp/tap
brew install --cask gister
```

## Maintenance

The cask ([`Casks/gister.rb`](Casks/gister.rb)) is updated automatically on each
published release by the `gister` repo's **Bump Homebrew cask** workflow.
